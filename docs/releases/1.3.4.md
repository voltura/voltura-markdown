# Voltura Markdown 1.3.4

## Improvements

- Add an integrated Find bar with match counts, previous/next controls, and match markers in the scrollbar.
- Add case-sensitive and whole-word search in the editor, with visible match highlights and Replace handoff.
- Improve split-editor wrapping, line numbers, and scrolling responsiveness.
- Refine insert dialogs and use the Explorer-style Open dialog.
- Add a context menu for document links.

## Download and use

- **VolturaMarkdown-Setup-1.3.4-win-x64.exe**: install for your Windows account or update an existing installation.
- **vmd.exe**: portable, single-file reader and editor. Download and run.

Both executables are self-signed and timestamped. Windows may show a publisher warning. No separately installed runtime is required. Source archives are for developers.
