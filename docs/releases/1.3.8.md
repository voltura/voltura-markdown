# Voltura Markdown 1.3.8

## Improvements

- Choose **Reload** or **Dismiss** when an open Markdown file changes on disk.
- Reload keeps your place in the reader where possible. The editor asks before discarding unsaved changes.

## Downloads

- **VolturaMarkdown-Setup-1.3.8-win-x64.exe** installs or updates the app for your Windows account.
- **vmd.exe** runs as a portable app.

Both executables are self-signed and timestamped. Windows may show a publisher warning.
