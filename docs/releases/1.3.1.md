# Voltura Markdown 1.3.1

## Fixes

- Preserve literal characters in inserted link labels and destinations, and keep local links intact when saving a document to a different folder.
- Improve heading conversion, outline labels, and continuation of lists that use tab spacing.
- Find overlapping whole-word replacement candidates correctly.
- Keep valid recovery drafts available when malformed recovery filenames are present.

## Download and use

- **VolturaMarkdown-Setup-1.3.1-win-x64.exe**: install for your Windows account or update an existing installation.
- **vmd.exe**: portable, single-file reader and editor. Download and run.

Both executables are self-signed and timestamped. Windows may show a publisher warning. No separately installed runtime is required. Source archives are for developers.
