# Voltura Markdown 1.3.6

## Improvements

- Use Explorer-style Save As dialogs for saving documents and exporting HTML or PDF.
- Refine confirmation dialogs with clearer buttons and light/dark styling.
- Keep header icons and preview panes steady while typing in Live mode.

## Download and use

- **VolturaMarkdown-Setup-1.3.6-win-x64.exe**: install for your Windows account or update an existing installation.
- **vmd.exe**: portable, single-file reader and editor. Download and run.

Both executables are self-signed and timestamped. Windows may show a publisher warning. No separately installed runtime is required. Source archives are for developers.
