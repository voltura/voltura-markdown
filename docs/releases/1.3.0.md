# Voltura Markdown 1.3.0

## What's new

- Copy a complete code block with one click. Recognized language labels use basic syntax coloring; inline code has a subtle background. Colored links show their destination on hover.
- Read richer HTML tables with merged cells, captions, nested tables, images, and alignment hints. HTML image dimensions, light/dark pictures, small text, subscripts, superscripts, and keyboard keys retain their supported presentation.
- View simple SVG badge text sharply across zoom and DPI changes. Adjacent Markdown badges wrap together while keeping their individual links.
- Open wide edit windows with source and Live preview side by side. Smaller windows retain the source/preview toggle; enabling Live stacks the panes. Choose **View mode** to return to reading.
- Menus, dialogs, file/print pickers, and editor scrollbars follow the light/dark app theme.
- Preserve preview heading navigation, synchronized scrolling after CRLF saves, individual HTML header cells on export, and horizontal rules inside table cells. Large rich table bands fall back to readable native child blocks to keep layout bounded.

## Download and use

- **VolturaMarkdown-Setup-1.3.0-win-x64.exe**: install for your Windows account or update an existing installation.
- **vmd.exe**: portable, single-file reader and editor. Download and run.

Both executables are self-signed and timestamped. Windows may show a publisher warning. No separately installed runtime is required. Source archives are for developers.

Open a document with **Ctrl+O**, drag it into the app, or pass its path to `vmd.exe`. **Ctrl+E** edits; **Ctrl+N** creates a draft; **Ctrl+S** saves explicitly; **F1** opens Help.

HTML is a native presentation subset: CSS and scripts are not executed. Exceptionally large rich table bands retain text, images, links, and formatting while omitting table geometry. See [supported formats and limits](https://github.com/voltura/voltura-markdown/blob/main/docs/COMPATIBILITY.md) and the [user guide](https://github.com/voltura/voltura-markdown/blob/main/docs/USER-GUIDE.md).
