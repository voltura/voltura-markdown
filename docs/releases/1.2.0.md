# Voltura Markdown 1.2.0

## What's new

- Read and edit Markdown in the same compact Windows app. **Ctrl+E** edits the current file; **Ctrl+N** starts a new draft. A missing full startup path offers to create a document there.
- Use heading levels, bold, italic, underline, links, code blocks, tables, lists, quotes, and image helpers. Find/Replace, a heading outline, smart list continuation, and bounded source highlighting help with longer documents.
- Work with live preview and synchronized scrolling. Validation points to unclosed fences, missing local files, and broken heading links without blocking Save.
- Paste or drop images into a managed assets folder, edit existing tables, link to headings, export HTML, and print through Windows printers, including Print to PDF.
- Recover background draft checkpoints after a crash. Explicit Save/Save As preserves existing encodings and checks for external changes; checkpoints never overwrite the original document.
- Enable optional stable update checks in Settings. Updates verify publisher signatures and checksums; manual updates restore unchanged open documents and reading positions. Unsaved drafts defer update restarts.
- Editor components load only when editing. Parsing, recovery, image copying, and export run in background jobs; incremental capture and bounded highlighting preserve responsiveness.

## Download and use

- **VolturaMarkdown-Setup-1.2.0-win-x64.exe**: install for your Windows account or update an existing installation.
- **vmd.exe**: portable, single-file reader and editor. Download and run.

Both executables are self-signed and timestamped. Windows may show a publisher warning. No separately installed runtime is required. Source archives are for developers.

Open a document with **Ctrl+O**, drag it into the app, or pass its path to `vmd.exe`. **Ctrl+S** saves explicitly; **F1** opens Help. New image assets require a saved document location. Crash recovery can lose edits since the last completed checkpoint.

See [supported formats and limits](https://github.com/voltura/voltura-markdown/blob/main/docs/COMPATIBILITY.md) and the [user guide](https://github.com/voltura/voltura-markdown/blob/main/docs/USER-GUIDE.md). MIT licensed.
