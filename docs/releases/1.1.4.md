# Voltura Markdown 1.1.4

## What's new

- Search shows the current match and total, such as **3 of 12**, and navigation shortcuts when there are multiple results and room to show them.
- The first match appears before background counting; next/previous navigation reuses the count. Matches retain about two text lines above them for context where possible.
- Fixes the search field's right edge and prevents the Windows beep when pressing Enter or Shift+Enter to navigate results.
- Prevents zoom-related scrollbar flicker, removes horizontal scrolling caused by empty centering margins, and uses the arrow cursor over scrollbar tracks.
- Production executables exclude test options, verification routines, failure injection, and diagnostic timing code. These remain in a separate development test executable.
- Retains the current website links and delayed default-reader correction from earlier releases.

## Download and use

- **vmd.exe**: portable, single-file reader. Download and run.
- **VolturaMarkdown-Setup-1.1.4-win-x64.exe**: install for your Windows account. Run Setup again to update an existing installation.

Both executables are self-signed and timestamped. No separately installed runtime is required. Source archives are for developers.

Open a document with **Ctrl+O**, drag it into the reader, or run:

```powershell
.\vmd.exe "C:\Documents\example.md"
```

Press **F1** for Help. Close the reader before updating; your documents and preferences are retained.

See [supported formats and limits](https://github.com/voltura/voltura-markdown/blob/main/docs/COMPATIBILITY.md). MIT licensed.
