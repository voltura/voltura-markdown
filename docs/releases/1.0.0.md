# Voltura Markdown 1.0.0

A compact, read-only Markdown viewer for Windows 10/11 x64.

## Download and use

Choose from the release's **Assets**:

- **`vmd.exe`** — portable reader; download and run.
- **`VolturaMarkdown-Setup-1.0.0-win-x64.exe`** — per-user Setup with a Start menu shortcut and uninstall entry. No administrator access required.

Source archives contain developer files, not a built app. No separate runtime is required.

Open a file with **Ctrl+O**, drag it into the window, or run:

```powershell
.\vmd.exe "C:\Documents\example.md"
```

**F11** switches window modes. **Escape** closes directly when launched with a file path, after dismissing search/Help/About. Without a file argument, it leaves fullscreen or closes a normal window. The fullscreen **X** closes directly. **F1** opens Help.

Setup's unchecked **Choose as default Markdown reader** option opens Windows Default apps for your selection. Registration is also available in the app's three-dot menu.

## Features

- Formatted Markdown and selectable, read-only source.
- Search, copy, smooth scrolling, and light/dark themes.
- Floating **− / percentage / +** zoom controls. Click the percentage to reset to 100%.
- Arrow-key scrolling in both directions.
- Tables, tasks, footnotes, alerts, Unicode, and local/HTTPS images.
- Common embedded HTML and themed keyboard keys; unsupported content stays readable in formatted view.
- Themed menus, tooltips, scrollbars, Help, and About.
- Copy file/name/path, show in Explorer, and choose an external editor.

## Update or remove

Close the reader, then replace the portable executable or run newer Setup. Uninstall through Windows Installed apps; documents and preferences are retained. Register again if you move a registered portable copy.

## Supported scope

Editing, printing, syntax highlighting, arbitrary HTML/CSS layouts, animated images, Mermaid, and mathematical typesetting are not included. Very large documents require memory proportional to their content and structure.

See [supported formats and limits](https://github.com/voltura/voltura-markdown/blob/main/docs/COMPATIBILITY.md). MIT licensed; dependency notices are available in About. Exact hashes, sizes, and signing status follow below.
