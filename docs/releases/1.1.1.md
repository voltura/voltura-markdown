# Voltura Markdown 1.1.1

## What's new

- Starts in a normal window when opened without a document. Opening a document still respects the **Start fullscreen** preference.
- Opens Voltura Markdown's page in Windows Default apps where supported. You confirm the final choice for `.md` files in Windows; no administrator rights are required.
- Clearer installer welcome and completion text.

## Download and use

- **vmd.exe**: portable, single-file reader. Download and run.
- **VolturaMarkdown-Setup-1.1.1-win-x64.exe**: install for your Windows account. Run Setup again to update an existing installation.

Both executables are self-signed and timestamped. No separately installed runtime is required. Source archives are for developers.

Open a document with **Ctrl+O**, drag it into the reader, or run:

```powershell
.\vmd.exe "C:\Documents\example.md"
```

Press **F1** for Help. Close the reader before updating; your documents and preferences are retained.

See [supported formats and limits](https://github.com/voltura/voltura-markdown/blob/main/docs/COMPATIBILITY.md). MIT licensed.
