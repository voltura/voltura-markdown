# Voltura Markdown 1.1.3

## What's new

- If .md files point to Voltura Markdown at another location, the reader offers **Open Default apps** to register this copy and let you confirm it in Windows Settings. You can dismiss the notice until the next launch.
- Association checks start after the first content is visible and run in the background, preserving fast software-first startup. Reading and closing stay responsive while Windows checks associations.
- Retains the faster software-first renderer and HTTPS product website from earlier versions.

## Download and use

- **vmd.exe**: portable, single-file reader. Download and run.
- **VolturaMarkdown-Setup-1.1.3-win-x64.exe**: install for your Windows account. Run Setup again to update an existing installation.

Both executables are self-signed and timestamped. No separately installed runtime is required. Source archives are for developers.

Open a document with **Ctrl+O**, drag it into the reader, or run:

```powershell
.\vmd.exe "C:\Documents\example.md"
```

Press **F1** for Help. Close the reader before updating; your documents and preferences are retained.

See [supported formats and limits](https://github.com/voltura/voltura-markdown/blob/main/docs/COMPATIBILITY.md). MIT licensed.
