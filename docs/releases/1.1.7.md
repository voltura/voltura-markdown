# Voltura Markdown 1.1.7

## What's new

- Adds **Copy path** beside the existing default-app notice actions. It copies the full path to the running executable for use in Windows' app picker.
- Keeps the existing title and explanation, with brief feedback inside the button and no extra dialog or expanded notice.

## Download and use

- **vmd.exe**: portable, single-file reader. Download and run.
- **VolturaMarkdown-Setup-1.1.7-win-x64.exe**: install for your Windows account or update an existing installation.

Both executables are self-signed and timestamped. No separately installed runtime is required. Source archives are for developers.

Open a document with **Ctrl+O**, drag it into the reader, or pass its path to `vmd.exe`. Press **F1** for Help. Close the reader before updating; your documents and preferences are retained.

See [supported formats and limits](https://github.com/voltura/voltura-markdown/blob/main/docs/COMPATIBILITY.md). MIT licensed.
