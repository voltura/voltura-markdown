# Voltura Markdown 1.0.0 Preview 2

The portable reader and Windows installer now have timestamped, self-signed digital signatures from Voltura AB.

## Download

- **vmd.exe** — portable reader. Download and run; no installation required.
- **VolturaMarkdown-Setup-1.0.0-win-x64.exe** — installer for your Windows account, with a Start menu shortcut and uninstall entry.

Both downloads support Windows 10/11 x64. Choose the executables under **Assets**, rather than the source archives.

## Use or update

Close the reader before replacing the portable executable or running Setup again. Documents and preferences are retained.

Open a document with **Ctrl+O**, drag it into the viewer, or run:

```powershell
.\vmd.exe "C:\Documents\example.md"
```

Press **F1** for Help. **F11** switches fullscreen/windowed mode.

## Signature status

These signatures are self-signed. Windows may still display publisher or reputation warnings. SHA-256 checksums are included below and in **SHA256SUMS.txt**.

This remains a preview release. See the repository's compatibility guide for supported formats and validation limits.
