# Voltura Markdown 1.1.2

## What's new

- The app's About link, executable metadata, installer website and signing website URL now point to [markdown.voltura.se](https://markdown.voltura.se/).
- The product website uses its new HTTPS custom domain.

## Download and use

- **vmd.exe**: portable, single-file reader. Download and run.
- **VolturaMarkdown-Setup-1.1.2-win-x64.exe**: install for your Windows account. Run Setup again to update an existing installation.

Both executables are self-signed and timestamped. No separately installed runtime is required. Source archives are for developers.

Open a document with **Ctrl+O**, drag it into the reader, or run:

```powershell
.\vmd.exe "C:\Documents\example.md"
```

Press **F1** for Help. Close the reader before updating; your documents and preferences are retained.

See [supported formats and limits](https://github.com/voltura/voltura-markdown/blob/main/docs/COMPATIBILITY.md). MIT licensed.
