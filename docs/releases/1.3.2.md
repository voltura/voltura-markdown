# Voltura Markdown 1.3.2

## Fixes

- Navigate correctly to repeated headings, headings inside lists, and HTML headings with explicit identifiers.
- Respect zero and negative HTML list starting numbers and item numbering overrides.
- Remove optional closing hashes when converting headings to normal text.
- Preserve nested quote markers, task-list spacing, and enclosing quotes when leaving an empty list.
- Protect fenced and indented code from table-editing commands and preserve a table's final-newline state.
- Validate literal entity-like filenames correctly and retain document targets for query-only links during Save As and HTML export.
- Keep separate tables separate and long code blocks continuous in HTML exports; preserve cell vertical alignment and nested quote depth.
- Reject malformed numeric entities and honor explicit UTF-8 encoding even when a file contains damaged bytes.

All 20 fixes have regression coverage. The release passed nine test suites, 652 CommonMark examples, and isolated native editing, navigation, startup, and search checks.

## Download and use

- **VolturaMarkdown-Setup-1.3.2-win-x64.exe**: install for your Windows account or update an existing installation.
- **vmd.exe**: portable, single-file reader and editor. Download and run.

Both executables are self-signed and timestamped. Windows may show a publisher warning. No separately installed runtime is required. Source archives are for developers.
