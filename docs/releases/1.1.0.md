# Voltura Markdown 1.1.0

## What's new

Documents now display their first page using software rendering while hardware rendering prepares in the background. The transition preserves your reading position and selection. If hardware setup fails, the reader continues in software.

Small-file startup improved in local testing. The same startup approach applies to all document sizes.

## Download and use

- **vmd.exe**: portable, single-file reader. Download and run.
- **VolturaMarkdown-Setup-1.1.0-win-x64.exe**: install for your Windows account. Run Setup again to update an existing installation.

Both executables are signed and timestamped. No separately installed runtime is required. Source archives are for developers.

Open a document with **Ctrl+O**, drag it into the reader, or run:

```powershell
.\vmd.exe "C:\Documents\example.md"
```

Press **F1** for Help. Close the reader before updating; your documents and preferences are retained.

See [supported formats and limits](https://github.com/voltura/voltura-markdown/blob/main/docs/COMPATIBILITY.md). MIT licensed.
