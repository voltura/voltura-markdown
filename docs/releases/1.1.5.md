# Voltura Markdown 1.1.5

## What's new

- Prevents crashes and hangs caused by malformed SVG styles and excessive stroke-dash processing.
- Safely handles incomplete SVG CSS declarations and malformed transforms.
- Keeps HTML entity decoding fast on long documents and checks cancellation during preprocessing.
- Rejects invalid local link filenames that could be interpreted as application options.
- Cancels queued image work from the previous document so current images are not delayed by obsolete requests.
- Recovers cleanly if a drawing brush cannot be created.
- Improves background-worker behavior when memory allocation fails.
- Keeps product-page download filenames and displayed versions aligned with the selected release.

## Download and use

- **vmd.exe**: portable, single-file reader. Download and run.
- **VolturaMarkdown-Setup-1.1.5-win-x64.exe**: install for your Windows account or update an existing installation.

Both executables are self-signed and timestamped. No separately installed runtime is required. Source archives are for developers.

Open a document with **Ctrl+O**, drag it into the reader, or pass its path to `vmd.exe`. Press **F1** for Help. Close the reader before updating; your documents and preferences are retained.

See [supported formats and limits](https://github.com/voltura/voltura-markdown/blob/main/docs/COMPATIBILITY.md). MIT licensed.
