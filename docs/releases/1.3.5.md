# Voltura Markdown 1.3.5

## Improvements

- Add a themed, draggable divider to resize side-by-side and stacked Live editor panes.
- Keep preview resizing smooth and clear stale text fragments from the margin beside the source scrollbar.
- Make Shift+Enter insert a Markdown source newline so code fences and line numbers remain aligned.

## Download and use

- **VolturaMarkdown-Setup-1.3.5-win-x64.exe**: install for your Windows account or update an existing installation.
- **vmd.exe**: portable, single-file reader and editor. Download and run.

Both executables are self-signed and timestamped. Windows may show a publisher warning. No separately installed runtime is required. Source archives are for developers.
