A compact Markdown reader with optional source editing for Windows 10/11 x64.

## Download

- **`vmd.exe`** — portable; download and run.
- **`VolturaMarkdown-Setup-<version>-win-x64.exe`** — per-user installation, no administrator access required.

Choose an executable under **Assets**, not a source archive. Setup's optional default-reader checkbox opens Windows Settings for your selection.

Open a document with **Ctrl+O**, drag-and-drop, or:

```powershell
.\vmd.exe "C:\Documents\example.md"
```

**F11** switches window modes; **Escape** leaves fullscreen or closes a normal window. **F1** opens Help. Close the reader before replacing the portable file or running newer Setup. Uninstall retains documents and preferences.
