Help

Questions and answers

How do I open my Markdown files?

Choose whichever is easiest:

  • Open the app and choose a file.
  • Drag a .md file onto the reader window.
  • Using the portable copy? Drag a document onto vmd.exe.

Opening the app without a document starts in a window. Opening a document starts fullscreen unless Start fullscreen is disabled. Press F11 to switch modes.

Can I make it my default Markdown reader?

Yes. With Setup: select Choose as default Markdown reader on the final screen. The option starts unchecked.

From the reader:

  1. Keep the app in its permanent location.
  2. Open the three-dot menu and choose Register for .md files.
  3. In Windows Default apps, choose Voltura Markdown for .md.

Both options open Windows Default apps. You confirm the final choice there.

Can I edit a document?

Choose Edit Markdown from the three-dot menu or press Ctrl+E. Insert headings, tables, links, images or placeholders, lists, and code blocks. Wide windows start with Live source and preview side by side. Smaller windows start with the source/preview toggle; enabling Live stacks the panes. Save with Ctrl+S and choose View mode to return to reading.

Ctrl+N creates a new draft. Find/Replace, table editing, clipboard images, and local crash-recovery snapshots help with longer edits. Files save only when you choose Save. Edit file with… still opens another app.

Which HTML and code features are supported?

HTML tables support merged cells, captions, nested tables, images, and alignment hints. Images respect width and height; pictures can use light/dark sources. Small text, subscripts, superscripts, and keyboard keys retain their formatting. Colored links show their destination on hover.

Code blocks have a copy icon and basic syntax coloring for PowerShell, JavaScript/TypeScript, C#, C/C++, Python, JSON/JSONC, SQL, and shell/Bash. Menus, dialogs, file/print pickers, and editor scrollbars follow the app theme.

This is a native presentation subset: CSS and scripts are not executed. Exceptionally large rich table bands show readable child blocks instead of table geometry. See the supported formats and limits for details.

How do I update or remove it?

Close the reader first.

  • Update a portable copy: replace it with the new vmd.exe.
  • Update an installed copy: run the newer Setup.
  • Uninstall: remove Voltura Markdown through Windows Installed apps.

Your documents and saved preferences are preserved.

Optional Automatic updates in the three-dot menu downloads newer stable releases after signature and checksum verification and installs on close. It is off by default. Manual updates restore unchanged open documents and reading positions; modified drafts defer update restarts.
