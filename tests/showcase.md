# A quieter way to read.

Welcome to **Voltura Markdown** — a small, native home for your documents.

Great tools get out of the way. Open a file, settle into the typography, and let the ideas take the whole screen.

## Everything in its place

- **Fast by design.** Native text, a compact executable, and no browser runtime.
- **Made for reading.** Select a sentence, copy a passage, or find the next idea.
- **Your light.** A calm light palette and a rich dark palette.

> The details are the design. Small controls, thoughtful space, and a clear path through the page.

### A little structure

| Feature | Shortcut | Ready |
| :--- | :--- | :---: |
| Open a document | Ctrl+O | Yes |
| Find a phrase | Ctrl+F | Yes |
| Read fullscreen | F11 | Yes |
| View the source | Ctrl+Shift+V | Yes |

```cpp
// One file. One reader. Your words.
vmd.exe "C:\Documents\a good idea.md"
```
